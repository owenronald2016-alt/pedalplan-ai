# PedalPlan AI

PedalPlan AI is an AI-powered cycling and bikepacking planner designed to help cyclists create personalized itineraries, explore routes, estimate budgets, and prepare for their adventures.

**Live Demo:** https://pedalplan-ai.onrender.com/

**Repository Status:** This public repository contains an earlier version of the project and may not reflect all features available in the current live demo.

The project has been an ongoing learning journey in AI application development, route planning, mapping, and building practical tools for cyclists.
